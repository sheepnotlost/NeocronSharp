# NeocronSharp

## Register
product

## Users and purpose
For the user playing Neocron Evolution on this computer. The main workflow is
inspecting nearby NPCs, their client-side stats and locations while playing.
The user has asked to replace the abstract radar with the game's sector maps
and accurately positioned NPC markers. Existing navigation remains available.

## Personality
Quiet, practical, readable. The user explicitly requests a milky gray tone.
The supplied game-map screenshot is the geographic reference, not a request to
copy the neon-green HUD treatment across the desktop application.

## Principles
Use actual game map assets and verified coordinate transforms. Clearly show
the current sector, player, selected NPC, and unavailable map/data states.
Use familiar desktop controls and a restrained, consistent neutral palette.
Keep dense NPC data readable. Do not infer enemy/friendly status from color.
Retain keyboard access, text labels and shape differences for map markers.
Avoid distracting animation, gratuitous decoration and low-contrast gray text.
